# Data provenance

Frozen normalized DataFinder inputs derived from commit 18444c67611c1729af702faa79128a402a1643b2 at https://github.com/viswavi/datafinder . The upstream Apache 2.0 license is retained as DATAFINDER_LICENSE. Dataset descriptions retain their source ownership. Changes include whitespace-only ID normalization, merging duplicate IDs, retrospective split assignment, preservation of missing positives and decoded fallback query text for five IDs. No team original documents or HF training samples are included.

The implementation is a baseline, not a new retrieval algorithm. See the report for limitations and the retrospective evaluation context.
